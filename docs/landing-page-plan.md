# ランディングページ調整案（本番公開前 — 実装は別コミット）

> 目的: 「歯科医師・歯科医療従事者向けの症例ビジュアル作成ツール」であることが
> 3秒で伝わる LP にする。NARRATIVE CHERISH の上質さは維持しつつ、
> 医療系SaaSとして **対象者・機能・制限・料金・保存期間** を一目で分かる構成に。

## 構成（上から順）

### 1. Hero
- ロゴ + `CASEFLOW STUDIO™ for DENTISTRY`
- H1: **治療後の姿を、その場で見せられる。**
- サブ: 歯科医師・歯科医療従事者のための症例ビジュアル作成ツール。
  治療後イメージの視覚化、ビフォーアフターの共有、モーフィング動画づくりを、診療の流れの中で。
- CTA（3つ・優先順）:
  1. **招待コードで始める**（primary）
  2. **ログイン**（secondary）
  3. **料金を見る**（text link → 料金セクションへスクロール）
- Hero 直下に小さく: 「現在は招待制ベータです」

### 2. 機能（3カード）
| カード | コピー |
|---|---|
| **Visual Simulation Studio** | 症例写真から治療後イメージを生成。ホワイトニング・矯正・補綴など、患者説明のためのビジュアルを数十秒で。 |
| **Morphing Video Studio** | ビフォー→アフターを滑らかにつなぐモーフィング動画。カウンセリングでの「伝わり方」が変わります。 |
| **Photo Manager / 一時ライブラリー** | 症例写真と生成結果を患者・症例ごとに整理。**48時間の一時保存**— 長期クラウド保管は行いません。 |

### 3. 使い方（3ステップ）
撮る/選ぶ → 生成する（1生成 = 2トークン）→ 患者と一緒に見る・共有する

### 4. 料金（トークン制の説明を先頭に）
- 「1生成 = 2トークン。**生成に失敗した場合、トークンは消費されません（自動返却）**」
- Trial: 無料 10 tokens（約5生成分）
- Personal: **月額1,500円 / 100 tokens**（個人の歯科医師向け）
- Clinic: **月額5,000円 / 500 tokens**（医院・チーム向け）
- 追加トークン: Mini 500円/20 · Standard 2,000円/100 · Plus 5,000円/300
- 招待について: 招待コードで登録すると 10 tokens、紹介した方に 5 tokens
- CTA: 「料金プランを見る」→ 既存 pricing モーダル

### 5. 信頼・制限の明示（免責ブロック — 省略不可）
枠で囲い、小さすぎない文字サイズで:
- 本サービスは **AI診断を行うものではありません**
- **治療結果を保証するものではありません**
- 歯科医師・歯科医療従事者による **説明・症例整理・患者コミュニケーションを補助する** ためのツールです
- アップロード画像・生成画像・動画は **48時間の一時保存** です（長期クラウド保管サービスではありません）
- 患者氏名・電話番号・生年月日・カルテ番号などの **直接識別情報は保存しない設計** です
  （症例は匿名の患者コードで管理します）
