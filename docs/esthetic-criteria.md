## 0. 前提

歯科審美診査は、単に「白い歯」「まっすぐな歯」「左右対称な歯」を目指すものではない。顔貌、口唇、歯列、歯冠形態、歯肉、歯周組織、咬合、発音、年齢変化、患者の希望を総合的に評価し、どこを改善し、どこに自然な個性を残すかを判断するための診査である。

4層に分けて整理する：
1. **Macro Esthetics / マクロ審美** — 顔貌、正中、水平基準、咬合平面、顔面比率。
2. **Mini Esthetics / ミニ審美** — 口唇、スマイルライン、歯の露出量、スマイルアーク。
3. **Micro Esthetics / マイクロ審美** — 歯冠形態、幅径比、歯軸、コンタクト、エンブレジャー、色調、表面性状。
4. **Pink Esthetics / ピンク審美** — 歯肉ライン、ジンジバルゼニス、歯間乳頭、歯周組織、生物学的許容範囲。

審美診査の目的は、すべての患者を同じ理想形に近づけることではない。顔貌・唇・歯・歯肉・年齢・機能・個性の間で、どの程度まで整え、どの程度の自然な揺らぎを残すかを判断することである。

------------------------------------------------------------
## 1. Facial Analysis / 顔貌分析

### 1-1. Facial Midline / 顔面正中線
眉間・鼻尖・人中・上唇中央・オトガイを結ぶ垂直軸に対し、上顎中切歯間正中の一致を確認。臨床的には完全一致より「上顎中切歯正中が顔面正中に平行であること」が重要。軽度の正中偏位は顔貌・口唇の非対称と調和していれば修正対象とは限らない。正中の傾斜は位置ズレ以上に違和感が強い。

### 1-2. Horizontal Reference Lines / 水平基準線
瞳孔間線・口角線・切縁平面・前方咬合平面。理想的には大きく破綻せず自然な平行性。ただし顔は本来非対称で、写真上で完全水平補正しすぎると人工的に見える。

### 1-3. Facial Proportion / 顔面比率
上顔面・中顔面・下顔面の3区分。「1：1：1」は目安であり絶対基準ではない。咬合高径、口唇閉鎖、ガミースマイル、下顔面高の評価に用いる。

### 1-4. Profile Analysis / 側貌分析
口唇突出感、E-line、鼻唇角、オトガイ位置、下顔面高、リップサポート。審美補綴で前歯唇側豊隆を過度に増やすと口元が突出して見える。ラミネートベニア・前歯部クラウン・ダイレクトボンディングでは側貌のリップサポートを確認。

------------------------------------------------------------
## 2. Lip Analysis / 口唇分析

静止時・会話時・スマイル時の動的評価が重要。

### 2-1. Incisal Display at Rest / 安静時切端露出量
上唇長・厚み・年齢・性別・歯冠長・切縁位置・咬耗・咬合高径に依存。若年で上顎前歯露出が多く、加齢で上顎露出が減り下顎露出が増える。目安は上顎切歯 2〜4mm 程度だが機械的に適用しない。

### 2-2. Smile Line / スマイルライン（Lip Line / リップライン）
- Low（低位）：歯冠が十分見えない。落ち着いた／加齢的。
- Average（平均）：上顎前歯の大部分〜全体が見える。自然で調和。
- High（高位）：歯肉も帯状に見える。歯肉ライン左右差・補綴マージンが目立つ。
スマイル時 1〜2mm の歯肉露出は許容され得る。3mm 以上はガミースマイルと認識されやすい。

### 2-3. Gummy Smile / ガミースマイル
原因別：受動的萌出異常／上顎垂直過成長／上唇過可動／短い上唇／歯槽性挺出。原因により治療方針が異なる。

### 2-4. Smile Arc / スマイルアーク
上顎前歯切縁カーブと下唇上縁カーブの関係。
- Consonant（調和型）：切縁カーブが下唇カーブと平行／一致。若々しく自然。
- Flat（平坦型）：人工的・義歯的・加齢的。
- Reverse（逆カーブ型）：不調和が強い。
摩耗・過度な圧下・補綴切縁設定ミスで平坦化する。

### 2-5. Buccal Corridor / バッカルコリドー
口角と臼歯部頬側面の暗いスペース。完全に消すべきではなく、適度な陰影は自然さに寄与。過度に広いと歯列弓が狭く見える。

------------------------------------------------------------
## 3. Dental & Arch Analysis / 歯冠・歯列分析

### 3-1. 上顎中切歯の位置
切縁位置が最重要基準。これが決まると歯冠長・側切歯/犬歯位置・スマイルアーク・歯肉ライン・咬合平面・発音が連動。

### 3-2. Width-to-Height Ratio / 歯冠幅径比
上顎中切歯は一般に **75〜85%** が目安（幅÷長×100）。70%前後＝細長い／78〜82%＝標準調和／85%以上＝四角く重い。ラインアングルと光の反射域で「見かけの幅」を調整。

### 3-3. 歯冠形態のタイプ
- **Square / スクエア**：辺縁が平行、歯頸部幅広い、コンタクト長い。安定感・力強さ。歯間乳頭を支えやすくブラックトライアングルが目立ちにくい。四角くしすぎると人工的。
- **Ovoid / オーバル（卵円形）**：丸みを帯び隅角なだらか。自然・柔らかい・若々しい。多くの顔貌に調和。丸めすぎると幼く存在感が弱い。
- **Triangular / トライアンギュラー（三角形）**：切縁側広く歯頸部狭い、コンタクトが切縁側。シャープ・繊細。ブラックトライアングルが生じやすく、コンタクトを歯頸側へ下げる設計が重要。
- **Hybrid / 混合型**：実際の天然歯は中間型が多い（Square-Ovoid / Ovoid-Triangular / Square-Tapered 等）。

歯冠形態は歯肉・歯間乳頭の見え方に影響。ブラックトライアングル症例では隣接面をスクエア寄りに補正しコンタクトを歯頸側へ。顔の形と歯の形を機械的に一致させる考えは絶対基準ではない。

### 3-4. Golden Proportion / 黄金比
正面観で 中切歯：側切歯：犬歯 = 1.6：1.0：0.6 とされることがあるが、絶対基準ではなく初期設計・患者説明の補助線。

### 3-5. Tooth Axis / 歯軸
中央→側方で傾斜がわずかに増す。中切歯ほぼ垂直（わずかに遠心傾斜）、犬歯は遠心傾斜やや強く口角方向への流れ。

### 3-6. Contact Point / コンタクトポイント
中央→側方で歯頸側へ移動。ブラックトライアングルはコンタクトを歯頸側へ延長して改善し得る。

### 3-7. Incisal Embrasure / 切縁鼓形空隙
中央→側方で徐々に大きくなる。均一すぎると人工的・義歯的。

### 3-8. Line Angle / ラインアングル
光の反射境界。内側に寄せると細く、外側に広げると太く見える。左右非対称だと歪んで見える。

### 3-9. Shade / 色調
Hue / 色相、**Value / 明度（最重要）**、Chroma / 彩度、Translucency / 透明性、Fluorescence / 蛍光性、Opalescence / 乳白感、Surface Texture / 表面性状。乾燥で明度が上がるため処置前・湿潤状態で採得。モノクロ化で Value を確認。

------------------------------------------------------------
## 4. Gingival & Periodontal Analysis / 歯肉・歯周組織分析

### 4-1. Gingival Zenith / ジンジバルゼニス
歯肉辺縁の最も根尖側の点。中切歯はやや遠心寄り、側切歯は中央〜わずか遠心、犬歯はほぼ歯軸上。中切歯と犬歯の歯肉頂が近い高さ、側切歯がそれより約 **0.5〜1mm 歯冠側**にあると自然。

### 4-2. Gingival Level / 歯肉レベル
中切歯左右の不一致、側切歯過高位、一直線の人工的ライン、歯冠長左右差が目立ちやすい。

### 4-3. Interdental Papilla / 歯間乳頭
骨頂〜コンタクト距離、歯根間距離、歯冠形態、歯周組織の厚み等に依存。不足でブラックトライアングル。

### 4-4. Black Triangle / ブラックトライアングル
原因：骨吸収・歯肉退縮・三角形歯冠・コンタクトが切縁側すぎ・歯根離開・薄い歯肉フェノタイプ等。対応：ダイレクトボンディング（コンタクトを歯頸側へ延長）／矯正（歯根平行化）／補綴（隣接面・エマージェンス修正）／歯周形成外科（予知性に限界）。

### 4-5. Biological Width / Supracrestal Tissue Attachment
接合上皮＋結合組織性付着。補綴マージンが侵入すると慢性炎症・歯肉退縮・骨吸収・ブラックマージン等。歯冠長延長/矯正的挺出は健康な補綴スペース確保のため。

------------------------------------------------------------
## 5. White Esthetics / ホワイトエステティック
歯冠側評価：歯冠形態、歯冠比率、色調（Hue/Value/Chroma）、透明性、表面性状、配列、歯軸、切縁形態、ラインアングル。

## 6. Pink Esthetics / ピンクエステティック
歯肉側評価：歯肉レベル、ジンジバルゼニス、歯間乳頭、歯肉色、歯肉厚み（Thin/Thick phenotype）、エマージェンスプロファイル、補綴マージン。

## 7. 審美診査チェックリスト（要点）
- **A. Facial**：顔面正中と上顎正中の一致/平行性、瞳孔間線と切縁/咬合平面、口角線左右差、下顔面高、咬合高径、口唇閉鎖、プロファイル、顔貌非対称。
- **B. Lip**：安静時切端露出、スマイル時歯冠/歯肉露出、ガミースマイル、スマイルアーク、口角挙上、バッカルコリドー、上唇長/可動量、会話時の見え方。
- **C. Dental**：中切歯切縁位置/幅径比/左右対称、歯冠形態タイプ、側切歯形態、犬歯位置、歯軸、正中、捻転、叢生、空隙、コンタクト、エンブレジャー、ラインアングル、色調、透明性、表面性状、咬耗。
- **D. Gingival**：ジンジバルゼニス、歯肉ライン、左右差、歯間乳頭、ブラックトライアングル、歯肉色/厚み、炎症/BOP、退縮、エマージェンス、補綴マージン、Supracrestal Tissue Attachment。
- **E. Tooth Crown Shape**：スクエア/オーバル/トライアンギュラー、左右対称、幅径比、切縁側と歯頸側の幅差、近遠心の平行/収束、隅角、ラインアングル、コンタクト位置/長さ、切縁鼓形空隙、ブラックトライアングル助長の有無、歯肉ライン/スマイルアーク/顔貌・口唇・年齢・希望との調和。

## 8. CaseFlow Studio 用 5項目スライダー設計

1. **Shade / 色調** — 明度中心、彩度を下げすぎず、天然歯らしい透明性を残す。白くしすぎない。
2. **Alignment / 歯列** — 正中・歯軸・捻転・叢生・空隙・咬合平面・アーチフォーム・スマイル幅。まっすぐにしすぎない。スマイルアークと連動。
3. **Tooth Shape / 歯冠形態** — 内部パラメーター：歯冠幅／歯冠長／幅径比／歯頸部幅／切縁側幅／ラインアングル位置／隅角の丸み／コンタクトエリア長／切縁形態／表面性状。実寸だけでなく光の反射域で見かけを調整。
4. **Scallop / 歯肉ライン** — ジンジバルゼニス、歯間乳頭、ブラックトライアングル、立ち上がり、エマージェンス、左右差。白い歯で埋めると癒着して見える。
5. **Smile Frame / スマイルフレーム** — スマイルアーク、リップライン、切縁ライン、バッカルコリドー、口角挙上、スマイル幅、上唇/下唇と歯の関係。

------------------------------------------------------------
## 9. スライダーの補正レベル設計
- **左 / Current（現状）**：維持。
- **中央 / Evidence-Based（標準補正）**：臨床的に自然な範囲。過度な白さ・対称・歯列補正を避ける。
- **右 / Maximum Correction（最大補正）**：理想方向へ強く。ただし天然歯らしさ・歯肉/顔貌との調和を損なわない範囲。

## 10. モーフィング動画への応用
透過合成ではなく**ワープ変形**を主体に。切縁が滑らかに揃い、スマイル幅が広がり、口角が上がり、歯冠形態が連続的に、歯肉ラインが自然に整う治療ストーリー。避ける：Afterの透過重ね／コマ送り入替／歯冠の浮き／切縁長の不整合／唇・歯肉の二重残像／歯冠形態と歯肉ラインの非連動。

理想ストーリー：①現状認識 → ②切縁が下唇カーブに沿う → ③歯軸とスマイル幅改善 → ④歯冠形態が滑らかに整う → ⑤歯肉ライン/歯間乳頭が馴染む → ⑥口角が上がりスマイルフレームが明るくなる。

------------------------------------------------------------
## 11. 総合まとめ
①顔の中で歯列が自然に位置 → ②唇の動きと歯の見え方の調和 → ③中切歯切縁位置と歯冠比率 → ④歯冠形態の調和 → ⑤歯肉ライン/歯間乳頭 → ⑥色調/透明性/表面性状 → ⑦歯周組織と補綴マージンの生物学的妥当性 → ⑧過剰補正の回避。

審美診査の目的は、白く・まっすぐ・左右対称にすることではなく、顔貌・唇・歯・歯肉・年齢・機能・個性の間でどこまで整えどの程度の自然な揺らぎを残すかを判断すること。重要なのは、歯だけを理想形に置換するのではなく、顔貌・口唇・歯・歯肉が一体として自然に変化していくこと。
