# Smile Morph Studio — 企画・設計メモ

審美歯科症例ビジュアル制作アプリ。術前・経過・術後の最大10枚の写真を読み込み、
自然なモーフィング風プレビューを生成し、患者説明・症例記録・SNS投稿・院内プレゼン
向けの画像/動画として書き出す。

> **位置づけ**: 医療診断アプリではない。歯科医師監修下での患者説明・症例提示・
> SNS用ビジュアル制作の補助ツール。AIによる診断・治療結果の予測や保証は行わない。
> AI生成・仮処理の画像には必ず "Simulation / Reference Image" を表示する。

コンセプト: **Clinical Beauty, Visualized. / 臨床の美しさを、視覚化する。**

---

## アーキテクチャ方針（現時点）

- **フロントエンド = PWA（単体HTML/CSS/JS、外部ライブラリ最小）**。iPhone Safari に
  インストール可能。`app-v3/` が最新。`app/` は v2（参照用に保持）。
- **高品質エンジン = Python (`morph_video/`)**。オプティカルフロー(flow)/特徴点(feature)
  によるMP4モーフィングと審美評価・推奨治療を提供。PWAから将来サーバー連携して
  「本物のMP4書き出し」を行う拡張余地（PWA単体はCanvasプレビュー＋静止画書き出し）。
- ネイティブiOS(SwiftUI)は、PWAが配布の近道のため当面は後回し（将来オプション）。

## 開発フェーズ

### Phase 1 — モーフィング動画制作ツール（中核）
最大10枚読み込み / 並べ替え / 手動位置合わせ / 簡易自動補正 / モーフィング生成 /
テキスト・ラベル / SNS向け書き出し（9:16・4:5・1:1・16:9）/ 端末内保存・共有。

### Phase 2 — AI補助
術前・経過・術後の自動分類 / 顔貌スマイルの自動クロップ / 口腔内の向き補正 /
明るさ・色調補正 / 主訴候補検出 / キャプション・SNS投稿文の作成補助。

### Phase 3 — AI術後シミュレーター
マクロ/ミクロ解析 / 矯正・補綴・矯正＋補綴の術後参考イメージ生成 / 歯科医師の
修正・確認 / Simulation透かし / 患者説明用の比較画像。

## 個人情報・倫理設計（要件）
患者同意確認 / SNS同意の別管理 / 顔貌・口腔内の保存範囲設定 / 端末内処理優先 /
クラウド送信前確認 / 自動削除 / 匿名症例モード / AI生成への Simulation 表示 /
実症例とAI生成の明確な区別 / 治療結果を保証しない旨の表示。
