# Smile Morph Studio — PWA Prototype v3

審美歯科症例ビジュアル制作アプリの iPhone 確認用 PWA（v2 を壊さず改善した版）。
単体の `index.html`（外部ライブラリなし）で動作します。Replit / 任意の静的ホスティング /
`python3 -m http.server` 等でそのまま配信できます。

## v3 の改善点
1. **モーフィング品質**: 変化の重心を中央の口元・歯列に置くガウス包絡＋2周波ウェーブ＋
   わずかな中央寄せで「ぬるっと」した自然な変化に。外側の顔貌・背景は安定。合成は
   `lighter` をやめ通常のクロスディゾルブに変更（白飛び低減）。スマイル位置（位置合わせ）
   が変化の重心に反映されます。
2. **書き出し導線**: 書き出し後に「写真に保存 / ファイルに保存 / SNSに共有」を
   保存先の説明つきで明示（Web Share API + download）。iOS の保存制約を前提に、
   どこに保存されるか分かるUIに。
3. **AI術後シミュレーター（仮処理）**: 歯の明度↑（暖色白）・空隙閉鎖の中央圧縮・
   ブラックトライアントル改善の歯間乳頭描画・スマイル整え。矯正/補綴/矯正＋補綴で
   見た目の変化を差別化。画面に必ず "Simulation / Reference Image" を表示。
4. **写真の並べ替え**（タイル下の ‹ ›）と読み込みエラー時のスキップを追加。

## 使い方（ローカル確認）
```
cd app-v3
python3 -m http.server 8080
# iPhone/PC のブラウザで http://<PCのIP>:8080/  （カメラ/共有は https か localhost 推奨）
```

## 注意
本アプリは医療診断アプリではありません。治療結果を保証するものではなく、歯科医師による
患者説明・症例提示・SNS用ビジュアル制作の補助ツールです。`index.html` のモーフィングは
プレビュー用の補正であり、本格的な歯列ランドマーク変形や実AI術後生成ではありません。

高品質な MP4 モーフィング（オプティカルフロー / 特徴点）や審美評価は、リポジトリの
Python エンジン (`morph_video/`) を参照してください。
