# Smile Morph Studio Prototype v2

審美歯科症例ビジュアル制作アプリの iPhone 確認用PWAプロトタイプです。

## v2で直した点

- モーフィングをCSSクロスフェードからCanvas描画へ変更
- クロスフェード＋微細ズーム＋弱い液体ワープを追加
- 書き出し後に「Export Center / 保存先を選択」画面へ移動
- 共有、ファイル保存、別タブ表示を追加
- AIシミュレーターの仮処理で、明度変化・スマイル領域の可視化・変化量スライダーを追加

## 注意

これは本格的な歯列ランドマーク変形やAI術後生成ではありません。
Web/PWA版では、iOSの仕様上、アプリが写真アプリへ直接保存する挙動は保証できません。
「共有」から「画像を保存」「ファイルに保存」「Instagram」などを選択する設計です。
